# Table Some Tennis

A Pong-inspired table tennis game exported from Godot.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download the `Pong_application` folder and everything in it. You can run it directly from your downloads folder.
   Yeah, that’s about it.

Instructions for using the software:

1. Open the Pong application folder.
2. Run `new_ping_pong_export` application.
3. To test the networking capabilities, create two instances of the application and select 2 players on both of them. Have one application be player one and the other window be the other player. You will need to accept permissions in order for the program to use the LAN.
4. The right paddle is moved by the W, A, S, D keys, and the left paddle is controlled by mouse movement.
   *The left paddle is very slow while connected for some reason.*
